# 中文学术 AI 高频词汇风险参考

> **返回**: [SKILL.md](../SKILL.md)

本文档列出中文学位论文中常见的模板化词汇和空泛表达。它不是检测器规则表，也不保证替换后能降低某个工具的 AI 检测率；使用时应结合上下文判断，优先保留术语准确性和作者原意。

在执行词汇风险检查时，重点关注“密集出现、语义空泛、可删除不影响意思”的表达。

---

## 🔴 高风险词 (High-Risk Expressions)

**定义：** 这些词汇在 AI 改写文本中常密集出现。如果它们没有提供具体信息，应优先考虑删除、压缩或替换。

### 1. 累赘的连接与过渡词

| 本质 | AI 高频词 | 人类学术替代词 / 处理策略 |
|----|-----------|------------------------|
| 并列/补充 | **此外** / 更有甚者 / 与此同时 | 另外 / 同时 / （通常可以直接删除，用分号连接） |
| 背景设定 | **在这一背景下** / 在这个瞬息万变的时代 | 考虑到该问题 / 针对上述现状 / （结合具体应用场景重写） |
| 刻意总结 | **综上所述** / 总而言之 / 概括来说 | 本节表明 / 由此可见 / 实验结果说明 |

### 2. 夸大的修饰与评价词

| 本质 | AI 高频词 | 人类学术替代词 / 处理策略 |
|----|-----------|------------------------|
| 重要性 | **至关重要** / 不可或缺 / 极其重要 | 关键 / 核心 / 是...的基础 / 对...影响显著 |
| 影响程度 | **深远影响** / 革命性突破 / 完美 | 显著提升 / 有效改善 / 取得了具有统计学意义的改进 |
| 主观赞美 | 卓越的 / **宝贵的经验** / 充满活力的 | 优异的 / 客观证据 / 可靠的基准 |

### 3. 空泛的动作描述词

| 本质 | AI 高频词 | 人类学术替代词 / 处理策略 |
|----|-----------|------------------------|
| 动作 | **深入探讨** / 全面分析 / 系统梳理 | 详细评估 / 重点考察 / 针对...进行了推导 |
| 动作 | **充分体现** / 淋漓尽致地展现 | 表明 / 证实 / 符合...的假设 |

## 🟡 中风险词 (Medium-Risk Expressions)

**定义：** 人类在学术写作中也会使用，但密度过高时会显得模板化。无需机械删除，应结合段落语义分散或替换。

### 1. 结构与逻辑连接
- **然而 / 但是** → 替换方案：虽然 / 尽管如此 / 反观 / 与之相对
- **因此 / 鉴于此 / 基于此** → 替换方案：于是 / 从而 / 使得 / 故本文...
- **值得注意的是 / 有必要指出** → 替换方案：更为特殊的是 / 一个有趣的现象是 / （直接说重点）

### 2. 学术操作动词
- **揭示了 / 阐明了** → 替换方案：指出 / 发现了 / 说明 / 解释了
- **构建 / 打造 / 提供** → 替换方案：设计 / 提出 / 实现 / 搭建
- **缓解 / 解决** → 替换方案：改善 / 克服 / 减轻

### 3. 名词化表达
- **格局 / 全景 / 景象** → 替换方案：现状 / 分布 / 情况
- **织锦 / 交织 / 融合** → 替换方案：结合 / 组合 / 交叉应用

---

## 🟢 低风险词 (Low-Risk Expressions)

**定义：** 本身可正常用于论文。如果在同一段落中密集出现，或与上述高、中风险词共现，应检查是否可更具体。

- **表示包含/涉及**：涵盖、涉及、囊括、包含、具备
- **表示探究/分析**：剖析、摸索、探寻、探索、评估
- **表示结果/影响**：促使、推动、赋能、催生、导致

## 💡 实战词汇重构法则

### 法则 1：动作拆解化 (De-nominalization)

AI 喜欢把动词名词化以显得高级。将抽象名词还原为具体及物的动词。

❌ AI 原句："特征解耦机制起到了**至关重要**的作用，**提供了**解决过拟合的**新思路**。"
✅ 重构后："特征解耦机制有效**抑制**了过拟合，**避免**了特征塌陷。" (更精确的动词，去掉了虚无的"至关重要"和"新思路")

### 法则 2：废词剥离术 (Cut the fluff)

AI 生成句子时，开头经常挂着废话。直接从主语切入。

❌ AI 原句："**值得注意的是**，上述实验结果**充分证明了**本文模型架构的优越性。"
✅ 重构后："上述实验结果验证了本文模型的有效性。"

### 法则 3：具体化替换

优先使用论文中已有的具体对象、指标、实验设置和技术机制替换空泛套话。

- 不要为了“显得不像 AI”而引入生僻词、古风表达或口语化转折。
- 如果需要连接关系，优先选择符合中文学位论文语体的平实表达。

## ✅ 自查清单

重写一个段落后：
- [ ] 检查“此外、至关重要、探讨”等词是否密集或空泛。
- [ ] 检查“然而”、“因此”等连接词是否连续重复。
- [ ] 去除所有评价性质的主观溢美之词。
- [ ] 是否可以删掉段落开头的前 4 个字而不改变意思？（如果能，说明前4个字多半是AI过渡词，删掉它）
